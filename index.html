Le bot Discord ultime pour protéger vos percepteurs sur Dofus Touch.

➕ Inviter le bot

✨ Fonctionnalités principales

  • 🔔 Bouton de ping permetant la notifications lors d’attaques de percepteurs
  • 📊 Statistiques journalières et mensuelles
  • ⚔️ Suivi des alliances les plus agressives
  • 🏆 Classements : top défenseurs, top pingers, percos survivants
  • 🔥 Version Premium avec fonctionnalités exclusives

📖 Tutoriel rapide

  1. Invitez le bot sur votre serveur avec le bouton ci‑dessus.
  2. Donnez‑lui les permissions nécessaires (gestion des messages et embeds).
  3. Utilisez /perco_register pour parametrer le bot.
  4. Utilisez /start pour démarrer le bot.
  5. Pingez les attaques sur vos perco ! 🏅
